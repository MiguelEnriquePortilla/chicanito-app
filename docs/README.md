# Adding screenshots / demo GIF

The main [README](../README.md) has a placeholder for visuals right under the badges. To fill it in:

**Easiest way (no tools needed):** open the main `README.md` in GitHub's web editor and drag-and-drop images directly into the text — GitHub uploads them and inserts the markdown for you automatically.

**Suggested shots** (2-4 is plenty):
1. The swipeable menu feed (the most distinctive screen)
2. Cart drawer / "fly to cart" moment
3. Order confirmation screen with confetti
4. A short GIF of swipe → add to cart → WhatsApp handoff, if you can screen-record it on your phone

Once you have the files, put them in this `docs/` folder (e.g. `docs/feed.png`, `docs/demo.gif`) and reference them from the main README like:

```markdown
![Menu feed](docs/feed.png)
```
